新しく始めるなら、3ステップ。

  1. 簡単導入版を保存

    上のボタンからZIPをダウンロード。解凍はしません。

  2. Prismでインポート

    「インスタンスを追加」→「インポート」で、保存したZIPを選びます。

  3. 取得が終わったら起動

    日本語と翻訳パックは設定済み。サーバーガイドも入っています。

MOD本体はPrismが原配布元から取得します。一部のMODで手動ダウンロードが必要な場合は、Prismの案内に従ってください。Java自動選択を無効にしている場合はJava 8を指定してください。メモリー上限は4GBを指定済みです。

日本語になるところ

原版に同梱された日本語名を優先して、用語を合わせています。

  • クエスト全文1,511クエストの本文・タイトルなど、4,421項目
  • MODの表示・操作説明配布条件を確認できた5,646項目
  • 説明書とサーバーガイドTinkersの書籍386ファイルと、マルチ用ガイド

固有名や一部の画面には英語が残ります。追加翻訳34名前空間分は、再配布条件の確認が済んでいないため公開版に含めていません。未収録の一覧

使う前に知っておきたいこと

今のワールドをそのまま日本語化したい

原版1.1.2をプレイ中なら、追加用の日本語リソースパックを使ってください。簡単導入版は別のインスタンスを作るためのファイルです。既存環境への導入手順

クエストやレシピは変わる？

翻訳で進行条件やレシピは変更していません。簡単導入版も原版のMOD参照、クエスト判定、開始拠点を維持しています。原版との違い

翻訳と動作確認について

AI支援で翻訳し、用語・書式・参照・書籍構造を検査しています。元のローカル版では起動・接続を確認し、利用者から問題なく遊べたとの報告を受けています。簡単導入ZIPの新規インポートから起動までの実機テストと、全ページの目視確認は未実施です。検証内容

Prismの検索一覧から入れられる？

現在はこの配布所からZIPを取得し、Prismへインポートする方式です。CurseForge・Modrinthの検索一覧には登録されていません。

誤訳や表示の問題を見つけた

章・クエスト名や表示文と一緒に、日本語化のIssuesへ報告してください。翻訳データの編集・改変条件は、各ファイルのライセンスに従います。
